Page Architecture

How Solace pages are composed: floating nav islands, app mockup panels, section rhythm, and the solace-border-raised bevel.

Navbar (Optional)

The navbar is not enforced. Pages may use any navigation approach. The floating island style is one option, not a requirement.

App Mockup Panel

White panel with rounded top only, creating the illusion of the app rising from the page.

.mockup { rounded-t-2xl; border-b-0; overflow: hidden; bg: white }

Section Rhythm

1. Dark hero — product title + section number
2. App mockup — white, rounded top only
3. Light text section — #fff bg
4. Feature cards — solace-border-raised
5. Tinted accent — rounded panel, product color 8%
6. Alt accent section — rounded panel
7. Footer — rounded white panel, 4-column links

Accessibility (WCAG 2.1)

All text must meet WCAG AA minimum contrast (4.5:1 normal, 3:1 large). No exceptions. The most critical rule: never place dark text on a dark background. If the background is dark (neutral-0 through neutral-200), text must be #ffffff. If the background is light (neutral-600+), text must be #000000 or #505050.

This design system enforces WCAG AA compliance. The original site used white-on-primary (#fff on #ef5a3c = 3.39:1 FAIL); we fix this by using black-on-primary (#000 on #ef5a3c = 6.2:1 AA). All CTA buttons, gradient strips, and radius demos use the corrected contrast.
