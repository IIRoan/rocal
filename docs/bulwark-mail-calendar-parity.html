Web-first parity. Bulwark comparisons below prioritize Solace Web vs Bulwark. The native column is informational only — native mail is a separate track and not part of the current Stalwart porting effort. Stalwart boundary: mailbox read/write, identities, and JMAP mail operations only. Calendar views, events, invitations, subscriptions, and encrypted recent contacts are served by apps/backend APIs.

Recently shipped (Jun 2026)

  • Web list (early Jun): @tanstack/react-virtual scrolling, fixed 68px / 60px rows, 50-message pages, 150ms debounced load-more, merge-on-refresh, F5/Cmd+R JMAP refresh, scroll-to-selected
  • Web + native UI (mid Jun): recipient popover / sheet (copy, compose-to), identity badge (sub-address tags), MailIdentityBadge in list + reader
  • Recent contacts (19 Jun): E2EE recent-contacts payload, backend sync route, RecipientSuggestInput in mail compose + event participants (web + native)
  • Web compose depth (24 Jun): inline images (paste / drag-drop, resizable), edit existing drafts (seedDraft), plain-text mode toggle, signature above/below quote, forgotten-attachment warning, improved quoted HTML island, reply-identity auto-select
  • Web mail settings (24 Jun): display settings panel (external content ask/block/allow, light/dark/original appearance, trusted senders), compose settings panel
  • Web performance (24 Jun): neighbor message-body prefetch, mergeMailMessage body cache, faster list → reader transitions
  • Web mail depth (24 Jun): keyboard shortcuts (j/k/r/e/s/c/Escape/?), undo toasts on delete + archive, mark-as-read delay setting, thread prefetch (inbox+sent), thread expand in list, advanced search panel + filter chips, list density settings (compact/comfortable), sub-address tag suggestions in compose, layout-preserving quote island (Shadow DOM styles), parallel mail bootstrap on login, SPF/DKIM/DMARC auth badges in reader
  • Undo-send delay: not implementing — requires Stalwart delayed send support not currently available
  • Native compose: deferred — plain-text only today; not in current web-parity scope
  • Backend: Zod mail validation, external-recipient send fixes, timezone schema enforcement on events, invitation + subscription-auth fixes
  • Both: JMAP 401 retry + token clear on unauthorized
