Suggested roadmap (mail + calendar only)

P1 — Mail list feel ✓ shipped

  • Virtual scrolling (web)
  • Merge-on-refresh + scroll preservation
  • Debounced load-more
  • Native pagination (onEndReached)
  • F5 / Cmd+R → JMAP refresh (web)

P1 — Compose ✓ shipped (web)

  • Draft auto-save (web + native)
  • Rich text + HTML send (web)
  • Identity picker + signatures (web + native partial)

P2 — Mail depth

  • Web list thread prefetch (inbox+sent, rate-limit safe)
  • Label chips in list (compact) or density settings
  • Edit existing drafts from drafts folder
  • Native rich-text compose
  • Advanced search panel + chips
  • Thread expand in list
  • Undo toasts
  • Keyboard shortcuts (j/k, r, e, …)
  • Mark-as-read delay
  • Trusted senders

P2 — Calendar polish

  • Virtual location / video URL field
  • Mini-calendar sidebar (optional)
  • Event hover preview tuning
  • Native invite import parity with web

P3 — Optional

  • Scheduled send + undo-send delay
  • Mail layout options + density
  • Empty trash/junk
  • SPF/DKIM/DMARC badges
  • Tasks (only if product wants them)
