Monorepo using Bun workspaces. apps/web is a Next.js React 19 frontend with Tailwind CSS v4, shadcn/ui, Capacitor/Ionic mobile wrappers, and react-native-web. apps/backend is an Elysia.js API on Bun with Prisma/PostgreSQL, Better Auth, and AI via @openrouter/ai-sdk-provider. apps/notifications is a Go service for scheduled Resend email notifications. Shared packages live under packages/ including ui, mobile-ui, logger, calendar libs, and shared TS/ESLint configs.
