Windows/Bun workflow from repo root: `bun run install:all` installs dependencies, `bun run dev` starts all services, `bun run dev:frontend`, `bun run dev:backend`, and `bun run dev:notifications` start individual services. Quality checks: `bun run lint`, `bun run typecheck`, `bun run test`. Builds: `bun run build`. Backend DB commands are run in apps/backend: `bun run db:generate`, `bun run db:migrate`, `bun run db:deploy`, `bun run db:reset`. Common shell tools on Windows/PowerShell: `Get-ChildItem`, `Get-Location`, `Set-Location`, `git`, and `rg` when available.
