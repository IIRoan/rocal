Hardening needs a product decision (signed nonce from invite email), not a blind auth requirement. Partially mitigated by **001**.
- **SECURITY-04 (server-derived vault key)**: Real risk, but removing `derivedKeyB64` breaks native Hermes clients until a WASM argon2id path exists. Deferred — needs native coordination, not a backend-only quick fix.
- **DIRECTION-01 citing `enhanced-notification-service.ts`**: That file is dead code (**004**). Browser notifications are persisted by the backend but the Go worker only dispatches `notification_type = 'email'` (`apps/notifications/main.go:317`). Direction finding reframed below in the audit report.
- **PERF-04 (batched sync-log delete)**: Valid quick win but lower leverage than security/correctness items; not auto-planned.
