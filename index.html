Built for focus

Everything you need,
nothing you don't

A thoughtfully designed calendar app that keeps you in flow — on web, iOS, and Android.

Smart Calendar
An intuitive month and week view built for speed. Create, drag, and resize events with precision. Recurring events, all-day support, and timezone awareness built in.
Email Notifications
A dedicated Go-powered notification service sends timely reminders via Resend. Get daily digests, event alerts, and smart scheduling summaries directly to your inbox.
Passkey Auth
Sign in with Face ID, Touch ID, or a hardware security key — no passwords required. Powered by Better Auth with full WebAuthn support for a phishing-resistant experience.
Native Mobile
A full native experience on iOS and Android built with React Native and Expo. Native gestures, secure storage, and platform-specific polish without a web wrapper.
Fast by Default
The backend runs on Elysia.js with Bun — one of the fastest HTTP stacks available. Prisma + PostgreSQL for type-safe queries. Static export for sub-second page loads.
Monorepo Ready
A clean Bun workspace with shared packages for UI, logging, ESLint, and TypeScript config. Scale from solo project to team repo without restructuring your codebase.
