# Solace Design System

Before making any frontend change, read the relevant design doc files below.

## Design Docs

- `designdocs/solace-design-language.md` — primary reference: colors, typography, spacing, shadows, components, animation, dark mode
- `designdocs/solace-tailwind.config.js` — Tailwind theme config with all design tokens
- `designdocs/solace-variables.css` — CSS custom properties for all tokens
- `designdocs/solace-shadcn-theme.css` — shadcn/ui semantic color overrides
- `designdocs/solace-theme.js` — JS theme object
- `designdocs/solace-design-tokens.json` — machine-readable token export
- `designdocs/solace-preview.html` — visual reference of all components
